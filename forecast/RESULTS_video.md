# 영상 기반 구역 인원 예측 · 병목 시뮬레이션 — 결과 정리 (2026-11-18)

입력·특징 정의는 [`FEATURES_video.md`](FEATURES_video.md). 이 문서는 **결과, 근거, 예상 질문**을 모은다.

**한눈에**
- 광화문 43분 영상에서 **LightGBM(단순 설정) + 도착·이탈 예정 특징(A)** 이 같은 조건 최고: 직전값 대비 10초 뒤 **+13.3%**, 30초 뒤 +12.8%, 60초 뒤 +11.7%.

- 병목 판정용 JuPedSim 시뮬레이션을 **유전 알고리즘(GA)** 으로 실제 병목 실험에 보정: 검증 회차 밀도 오차 **1.04 → 0.39 명/㎡**, 문 교착 사라짐.
- 한계: 영상 1개(같은 카메라·같은 날), 사람이 적고(평균 5명) 병목 장면 없음.

## 3. 실험 설계 (누수 없음)

```
영상 시간  0초 ─────────────────────── 1231초 ───── 1539초 ─────────────────── 2565초
           │◀──── 학습(fit) ──────────▶│◀─ 검증 ──▶│◀──────── 평가(test) ────────▶│
           │◀────────── 학습 구간(앞 60%) ──────────▶│
```

- 학습 행: **정답 시각(t+H)이 1539초 전**인 행만. 평가: t ≥ 1539초.
- 검증(학습 구간 끝 20%): LSTM 조기 종료, 결합 가중치 선택에만 사용.
- 모든 특징은 시각 t까지의 값만 사용. `test_video_pipeline.py`에 '미래 값을 바꿔도 과거 예측이 그대로'인지 확인하는 테스트 있음(통과).
- 평가 행: 모든 모델이 값을 낸 **같은 시점**끼리만 비교(10초 뒤 2,032행, 30초 1,992행, 60초 1,932행).
- 기준선: 직전값(persistence, 지금 10초 평균 그대로). 개선율 = 1 − MAE(모델) / MAE(직전값).
- 차이 검증: 60초 블록 부트스트랩 2,000회, MAE 차이 95% 구간.

## 6. 모델·방법 선택 이유

| LightGBM + LSTM 평균 | 채택 후보 | 흔들림 절반(0.19명/초), 30초 +13.4%(A 포함) | 가중 평균은 검증 5분으로 가중치를 못 믿음 → 단순 평균 |

## 11. 시뮬레이션 보정 (JuPedSim + 유전 알고리즘)

### 11-1. 설정

| 항목 | 값 |
|---|---|
| 모델 | JuPedSim 1.4.2 CollisionFreeSpeedModelV2 (AnticipationVelocity·V3·SocialForce는 교착/오류로 탈락) |
| 사람 넣기 | 실제로 처음 보인 시각·위치(겹치면 0.1~0.3m 주변 빈자리, 안 되면 0.1초마다 재시도) |
| 유전자 | `desired_speed`, `time_gap`, `radius`, `strength_neighbor_repulsion`, `range_neighbor_repulsion` |
| 적합도 v1 | 문 앞 밀도 MAE + 통과 누적 MAE / 인원 |
| 적합도 v2 | v1 + 0.3 × \|최고 밀도 차\| + \|3명/㎡ 이상 시간 차\| / 회차 길이 (과대 추정 억제) |
| GA | 집단 20, 12세대, 토너먼트(3), BLX-α(0.3) 교차, 가우시안 변이(20%), 엘리트 2 |
| 학습/검증 | h0 12회차를 통로 폭별로 번갈아 6 / 6 |

### 11-2. 결과 (검증 6회차 = 보정에 안 쓴 회차)

| 지표 | 기본값 | GA v1 | GA v2 |
|---|---|---|---|
| 문 앞 밀도 MAE | 1.04 명/㎡ | **0.39 명/㎡** | 0.40 명/㎡ |
| 최고 밀도 오차(평균) | 0.67 명/㎡ | 0.85 명/㎡ | **0.71 명/㎡** |
| 3명/㎡ 이상 시간 오차(평균) | 17.2초 | 4.7초 | **4.5초** |
| 문 교착(못 지나간 사람) | 1회차에서 67명 중 47명 | 없음 | 없음 |
| 전원 통과 시각 차이 | −32 ~ +19초 | −9 ~ +5초 | **−8 ~ +4초** |
| 병목 판정 일치 | 5/6 | 5/6 | 5/6 (230회차 과대, 셋 다 같음) |
| 최고 밀도 — 폭 1.2m 090회차(실제 4.17) | 3.33 | 5.42 | **4.17** |
| 최고 밀도 — 폭 1.2m 170회차(실제 3.75) | 2.50 | 4.58 | **4.17** |
| 최고 밀도 — 폭 3.4m 270회차(실제 4.41) | 4.41(교착) | 6.32 | 7.06 (더 과대) |

학습 6회차: 밀도 MAE 기본값 0.87 → v1 0.17 → v2 0.17, 최고 밀도 오차 0.80 → 0.21 → **0.13**, 3명/㎡ 시간 오차 17.5 → 0.8 → **0초**, 병목 판정 6/6.

v2 해석: 적합도에 최고 밀도·지속 시간을 넣자 **좁은 통로(1.2m) 최고 밀도 과대가 사라졌지만**, 넓은 통로 다인원 회차(270)는 오히려 더 과대. GA가 바꾼 것은 밀어내는 범위(0.109 → 0.065m)뿐이고 **반경 0.135m는 그대로** → 적합도만으로는 한계.

v3(사람별 희망 속도 분포, 변동계수 0~0.3을 유전자로 추가, v2에서 출발): GA가 **변동계수 0을 골라 v2와 완전히 같은 결과** — 속도 차이를 주면 적합도가 나빠졌다. 속도 분포는 원인이 아님.

위에서 내려다본 위치 비교(`data-area/data/crowdqueue/ga_snapshot_*.png`)로 찾은 원인: 실제 사람들은 **문 쪽으로 좁아지는 부채꼴**로 서고 통로 양쪽 구석은 비며 뒤로 4~5m 늘어서는데, 시뮬레이션은 **문 앞 2m 구역의 폭 전체를 구석까지 꽉 채우고** 뒤쪽은 2~3m에서 끝난다(270회차 11초: 실제 4.4, v2 6.5명/㎡). 좁은 통로(1.2m)는 구석이 없어 잘 맞음.
다음 후보: 문 위 중앙 경유 지점(waypoint)으로 부채꼴 줄 흉내, 밀도 측정 영역을 문 중심 반원으로, 반경 하한(0.18m) 고정 후 재보정.

### 11-4. 예측 → 시뮬레이션 연결 테스트 (`data-area/forecast/bottleneck/sim_forecast_test.py`)

시각 t에 실제로 있는 사람을 실제 위치에 놓고, 앞으로 들어올 사람(유입)을 넣어 GA v2 시뮬레이션으로 10·20·30초 뒤 문 앞 밀도를 예측. 검증 6회차, t = 3초부터 5초 간격.
유입: oracle = 실제 유입 그대로(유입 예측이 완벽할 때) / rate = 최근 10초 유입 속도 유지 / none = 유입 없음.

| 방법 | MAE 10초 | MAE 20초 | MAE 30초 | 주의(3명/㎡) 판정 일치 10/20/30초 |
|---|---|---|---|---|
| 직전값 | 1.098 | 1.657 | 2.044 | 67% / 52% / 25% |
| LightGBM(어제, 회차 하나씩 빼고 학습) | **0.361** | — | — | 88% / — / — |
| 대기열 모형(어제) | 0.416 | — | — | 91% / — / — |
| 시뮬 기본값 + 실제 유입 | 0.471 | 0.920 | 1.060 | 85% / 81% / 67% |
| **시뮬 GA v2 + 실제 유입** | 0.482 | **0.462** | **0.400** | 91% / 95% / 92% |
| 시뮬 GA v2 + 유입 속도 유지 | 0.483 | 0.518 | 0.645 | 91% / 95% / 75% |
| 시뮬 GA v2 + 유입 없음 | 0.486 | 0.455 | 0.387 | 91% / 95% / 92% |

비교 시점: 10초 33개, 20초 21개, 30초 12개(회차가 7~67초로 짧음). 향후 30초 동안 3명/㎡ 이상인 시간 오차: GA v2 2.2초, 기본값 4.7초.

- **10초 뒤는 LightGBM이 가장 좋고, 20·30초 뒤는 보정한 시뮬레이션이 직전값보다 오차가 1/4~1/5.** LightGBM은 10초까지만 학습해 20초 이상은 비교 대상이 없음 → 역할 분담: 짧은 예측 = LightGBM, 20초 이상·병목 지속 = 시뮬레이션.
- 보정이 중요: 같은 실제 유입이라도 기본값은 20·30초 오차가 GA v2의 2~2.7배.
- 이 실험은 대부분의 사람이 처음부터 통로 안에 있어 **유입 예측의 가치가 드러나지 않음**(실제 유입 ≈ 유입 없음). 유입 속도 유지는 유입이 끝난 뒤에도 사람을 넣어 30초 뒤 오히려 나빠짐 → 실제 운영에서는 영상 예측(LightGBM·LSTM)이 유입량을 대신해야 하고, 유입이 길게 이어지는 장면에서 다시 검증 필요.
- 그림: `data-area/data/crowdqueue/simfc.png`(검증 회차별 실제 vs 20초 전 예측).

### 11-3. GA 파라미터의 현실성

| 파라미터 | 기본값 | GA v1 (v2) | 일반적으로 알려진 값(원문 미확인) | 설명 |
|---|---|---|---|---|
